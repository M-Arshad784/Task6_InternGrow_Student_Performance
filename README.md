# 📊 Task 5 — Student Performance Prediction

This project is **Task 5** of my **Machine Learning Internship at InternGrow**.
The goal is to analyze student-related data and build a machine learning model to predict student performance.

## 🚀 Project Overview

Student performance can be influenced by various academic and personal factors. In this project, the dataset is explored, preprocessed, and used to train machine learning models for predicting student performance.

## 🎯 Objectives

* Perform data preprocessing and cleaning
* Explore the dataset using EDA
* Identify important features affecting student performance
* Train machine learning models
* Evaluate model performance
* Compare predictions with actual results

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🔄 Workflow

1. Load the dataset
2. Perform data cleaning
3. Conduct Exploratory Data Analysis
4. Prepare features and target
5. Split data into training and testing sets
6. Train machine learning models
7. Evaluate model performance
8. Analyze the results

## 📈 Model Evaluation

The trained model is evaluated using appropriate regression/classification metrics depending on the prediction target.
